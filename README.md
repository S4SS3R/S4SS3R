## Current focus — SystemManager

A backend system for administrative and industrial maintenance workflows: preventive and corrective maintenance, equipment history, refrigerant consumption, reporting, billing, and auditable document management.

**Stack:** FastAPI · PostgreSQL · SQLAlchemy · Alembic · React / TypeScript (planned frontend)

**My role:** requirements analysis, architecture planning, business rules, technical decisions, testing strategy, and validation. AI coding assistants are part of the implementation workflow — my job is to define, decide, review, and verify, not to prompt and ship blindly.

The repository is currently private and in active development. It will be made public once it reaches a presentable state. Future projects built after SystemManager will also be public.
